# Programming_for_Scientists_Java_Code_Samples
Java code samples from Programming for Scientists Class (MA117)

## Assignment 1 - Circles on a Plane
Perform statistical analysis on large dataset of Circle data.

## Assignment 2 - Root Finding
Determine the roots of a complex polynomial using the Secant Method in Java. Create a Secant Fractal to represent results.

## Assignment 3 - Determinants of Matrices
Implement Java code that can compute the determinant of any $m \times n$ matrix, either directly or via Lower-Upper Decomposition.
