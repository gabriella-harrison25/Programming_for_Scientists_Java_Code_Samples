# Assignment 2 Overview
## Root Finding
*Complex.java* : Represents complex points, $z$,  in the complex plane.

*Polynomial.java* : Represents polynomials in $\mathbb{C}(z)$.

*Secand.java* : Given two intial COMPLEX points $z_0, z_1$, calculate the corresponding root of the polynomial using Secant method, if possible.

*Project2.java* : Generates a secant fractal to demonstrate results.
