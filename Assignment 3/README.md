# Assignment 3 Overview
## Determinants of Matrices

Goal: Write code to find the determinant of any $m \times n$ matrix, either directly or using Lower-Upper Decomposition of matrices.

*Matrix.java*: General class defining matrices and general operations.

*MatrixException.java* : Subclass of RuntimeException to throw matrix-related errors.

*GeneralMatrix.java* : subclass of Matrix that describes a general $m \times n $ matrix.

*TriMatrix.java* : subclass of Matrix that describes $n \times n$ real tri-diagonal matrix.

*Project3.java* : a separate class that uses Matrix and subclasses to collect basic statistics involving random matrices.

*VarGraph.pdf* : A graph of the variance of a set of random matrices based on matrix type.

*project3.pdf* : Full assignment description and instructions.
