# Assignment 1 Overview
## Circles on a Plane
Goal: Perform statistical analysis on large dataset of circles.

*Project1.java* : Represents points $(x,y)$ and establishes functions to find the Euclidean distance between two points.


*Circle.java* : Represents circles as a class and establishes function to determine if two circles are identical.


*Point.java* : Performs statistical analysis of the data provided using the previous two classes.


*project1.pdf* : Full assignment description and instructions.
